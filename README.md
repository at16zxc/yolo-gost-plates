# Распознавание нестандартных государственных регистрационных знаков

Решение задачи полуфинала дисциплины **«Искусственный интеллект и анализ данных» (АИС Город)** по обнаружению и распознаванию нестандартных государственных регистрационных знаков (ГРЗ).

---

## 1. Обзор решения
Решение построено на базе архитектуры **YOLOv8**, дообученной на гибридном датасете, сочетающем реальные фотографии и качественную синтетику. Пайплайн полностью автономен, работает в офлайн-режиме и оптимизирован для высокой производительности.

### Целевые группы знаков:
- **type1**: Стандартный однострочный знак (белый фон, чёрные символы).
- **type1a**: Квадратные (двухстрочные) знаки по ГОСТ Р 50577-2018 (праворульные и американские авто).
- **type1b**: Знаки транспортных средств для перевозки пассажиров (жёлтый фон, чёрные символы — такси, автобусы).
- **other**: Прочие объекты (прицепы, мотоциклы, дипломатические, иностранные знаки, витрины, рекламные щиты — корректно отсеиваются или маркируются как `other`).

## 2. Метрики и производительность
- **Среднее время инференса:** ~68.5 мс на одно изображение (на референсном процессоре / CPU), что с запасом укладывается в жёсткое требование ТЗ (< 100 мс).
- **Формат вывода:** Строгое соответствие спецификации (CSV с разделителем `;`, кодировка UTF-8).

## 4. Требования и установка
Для запуска требуется установленный Python 3.10+ и виртуальное окружение. Установите зависимости командой:
```powershell
pip install -r requirements.txt
```

---

## 5. Инструкция по запуску (Инференс)
Решение принимает на вход каталог с изображениями и генерирует итоговый CSV-файл с результатами.

Точная команда запуска из корневой директории проекта:
```powershell
python predict.py --input-dir <путь_к_каталогу_с_изображениями>
```

**Пример:**
```powershell
python predict.py --input-dir dataset/images/real/valid/images
```

Результат автоматически сохраняется в файл **`predictions.csv`** в корне проекта в следующем формате:
```csv
image;plate_num;plate_type;confidence
img_0042.jpg;A123BC716;type1a;0.93
img_0043.jpg;K5550P25;type1b;0.88
```

## 6. Датасет и источники данных
Датасет включает в себя:
1. **Реальные данные:** Собраны с использованием открытых датасетов и собственной разметки под специфику тусклого освещения, осадков и углов наклона.
2. **Синтетические данные:** Сгенерированы программно с фиксированным `random seed` для покрытия редких комбинаций символов и фонов.
